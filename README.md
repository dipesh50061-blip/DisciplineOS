# 🚀 Discipline OS AI

A productivity and self-improvement system designed to help students build consistency, track progress, and develop better study habits through analytics and gamification.

## 🌐 Live Demo

🔗 https://discipline-syst.netlify.app

---

## ✨ Features

- 📚 Subject Management
- 🤖 AI Study Planner
- ⏱ Study Session Tracking
- 📊 Weekly Analytics
- 🏆 Discipline Score System
- ⚡ XP & Level System
- 🍅 Pomodoro Timer
- 🧠 Mood Tracker
- 💬 AI Coach Personalities
- 🔐 User Authentication

---

## 👨‍💻 Development

The core logic, system design, and backend functionality were developed in Python by me.

The web interface (HTML, CSS, and JavaScript) was created with the assistance of AI tools to transform the Python-based system into an interactive browser experience.

This project reflects my focus on problem-solving, system design, and leveraging AI tools effectively to build practical applications.

---

## 🎯 Key Components

### 📚 Subject Management
Organize subjects, priorities, and weak topics.

### 🤖 Study Planner
Generate study plans based on priorities and available time.

### 📊 Analytics Dashboard
Track study hours, focus levels, and weekly performance.

### ⚡ XP & Level System
Gamified progression with XP and streak tracking.

### 🍅 Pomodoro Timer
Built-in focus timer for study sessions.

### 🧠 Mood Tracker
Track emotions and maintain self-awareness.

### 💬 AI Coach Personalities
Receive motivational messages from different coaching styles.
